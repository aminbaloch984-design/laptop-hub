## 4. Declarations you must answer honestly

- **Ads:** "No" while the app has no ads. Flip it to "Yes" the day AdMob ships.
- **Data safety:** the app sends the text of user messages to an AI provider — declare
  "App functionality" as the purpose, and that data is shared with a third party (Google).
  No account data, no location, no contacts.
- **Content rating:** complete the questionnaire; an AI chat app is normally Everyone / PEGI 3,
  but user-generated prompts can push it to Teen.
- **Target audience:** 13+ (do not opt into the Families programme).
- **Government / financial / health:** no.

## 5. Build the bundle

```powershell
cd NEW-AI
powershell -ExecutionPolicy Bypass -File mobile\build.ps1
```

This downloads JDK 17 and the Android SDK on first run, generates the Trusted Web Activity
project, and writes:

```
mobile\app-release-bundle.aab     <- upload this to Play Console
mobile\app-release-signed.apk     <- install this on your own phone to test
mobile\signing.keystore           <- BACK THIS UP. Losing it breaks future updates.
```

The keystore password is written to `mobile\keystore-password.txt`. Move both somewhere safe
and never commit them (they are already in `.gitignore`).

---

## 6. Digital Asset Links (removes the browser address bar)

A Trusted Web Activity only hides the URL bar when the site proves it belongs to the app.
That proof lives at the **domain root**, not under `/new-ai/`:

```
https://aminbaloch984-design.github.io/.well-known/assetlinks.json
```

`mobile/assetlinks.json` is generated by the build. Publish it from a repository named
`aminbaloch984-design.github.io` (GitHub Pages user site).

**Important:** after the first upload, Play re-signs the app with *Play App Signing*. Copy the
**SHA-256 of the app signing key** from Play Console → *Test and release → App integrity* into
`assetlinks.json` and push again. Until then the app opens with a thin URL bar on top, which
still works but is not the final look.

---

## 7. Order of operations

1. Build the AAB, install the APK on your phone, confirm chat works.
2. Fix the backend first — a dead backend fails review.
3. Create the Play Console app, upload the AAB to **Internal testing**, add yourself, install
   from the Play link, and copy the Play signing SHA-256 into `assetlinks.json`.
4. Fill the listing + declarations, then start the **closed test** with 12 testers.
5. After 14 days, apply for production.

---

## 8. Honest expectations about ads

AdMob needs the app to be live on a store, a payment profile, and a consent form. Realistic
revenue with a few hundred daily users is a few dollars per month; the AI provider bill grows
faster than ad revenue until you have thousands of daily users. Ship it, measure it, then
decide.
